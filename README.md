# Mini Games for SillyTavern

생성 응답을 기다리는 동안 가볍게 플레이할 수 있는 미니게임 확장입니다. API를 사용하지 않으며 채팅, 캐릭터, RP 내용에 접근하지 않습니다.

## 포함된 게임

### 지뢰찾기

- 기존 `ST-Classic-Minesweeper`의 게임 규칙과 조작 유지
- 초급: 9×9, 지뢰 10개
- 중급: 16×16, 지뢰 40개
- 첫 클릭 안전 처리
- PC: 좌클릭으로 열기, 우클릭으로 깃발, 열린 숫자 칸에서 양쪽 버튼을 함께 눌러 주변 열기
- 모바일: 짧게 눌러 열기, 길게 눌러 깃발, 열린 숫자 칸을 다시 눌러 주변 열기
- 모바일용 `칸 열기 / 깃발` 모드
- 모바일 게임창 하단에 간단한 조작 안내 표시
- 초급에서는 게임판 너비에 맞춰 창과 상태바 폭 자동 축소
- 모바일 중급에서는 16열이 내부 폭을 빈틈없이 채우도록 칸 크기 자동 계산
- 태블릿 중급에서는 게임판 너비에 맞춰 창을 축소해 양옆 빈 공간 제거
- 주변 깃발 수가 숫자와 맞으면 닫힌 칸을 한꺼번에 열며, 잘못된 깃발이면 지뢰 폭발

### 스파이더 카드게임

- 한 무늬(스페이드) 고정
- 10열, 104장, 완성 묶음 8개
- 내림차순 카드 묶음 이동
- 드래그 이동과 탭 선택 이동 지원
- 횟수 제한 없는 되돌리기
- 횟수 제한 없는 힌트와 이동 위치 강조 표시
- 모바일 화면 폭에 맞춰 카드 크기와 간격 자동 조절
- 카드 드래그 중 페이지 스크롤 잠금
- PC에서는 카드가 쌓여도 게임판 높이를 고정하고 내부만 스크롤
- 빈 열이 있으면 새 카드 배분 불가
- K부터 A까지 완성된 묶음 자동 제거

### 땅따먹기

- Volfied/Qix 계열에서 영감을 받은 오리지널 영역 점령 아케이드
- 선을 안전지대까지 연결해 적이 없는 쪽 영역 점령
- 목표 점령률 80%, 목숨 3개로 시작
- 스테이지가 올라가면 적 수와 이동 속도 증가
- 스테이지 클리어 시 목숨 1개 회복(최대 5개)
- 적이 그리는 중인 선에 닿거나 자신의 선을 가로지르면 목숨 감소
- PC: 방향키/WASD로 이동, 스페이스바로 선 긋기 토글
- 모바일·태블릿: 게임판 스와이프 또는 화면 방향 버튼으로 이동
- 모바일 `선 긋기` 버튼은 누르고 있을 필요 없는 토글 방식
- 게임판과 조작부에서 터치하는 동안 페이지 스크롤 방지
- 화면 폭에 맞춘 반응형 캔버스와 태블릿 최대 너비 제한
- 창을 다시 열면 3초 준비 카운트다운 후 재개

## 공통 기능

- `🕹️` 플로팅 버튼으로 열기/닫기
- 플로팅 버튼과 게임 창 드래그 이동
- 모바일 화면 밖으로 버튼과 창이 벗어나지 않도록 자동 보정
- 창을 닫으면 진행 상태를 유지한 채 타이머 일시정지
- 브라우저가 백그라운드로 전환되어도 진행 중인 게임 일시정지
- 게임 목록으로 돌아가면 현재 게임 종료
- 모든 게임에서 새 게임 시작 전 확인창 표시
- Windows Classic / 현재 실리태번 테마 / 사용자 테마
- 사용자 테마 생성, 복제, 삭제, JSON 내보내기·불러오기
- 기존 지뢰찾기 테마 JSON도 불러오기 가능
- 확장 설정 서랍은 기본적으로 접힌 상태로 표시

## 설치

1. 압축을 풉니다.
2. `ST-Mini-Games` 폴더 전체를 다음 위치 중 하나에 넣습니다.
   - 사용자별 설치: `SillyTavern/data/<사용자>/extensions/`
   - 전체 사용자 설치: `SillyTavern/public/scripts/extensions/third-party/`
3. SillyTavern을 새로고침합니다.

확장 폴더 이름은 `ST-Mini-Games` 그대로 유지해 주세요. 기존 `ST-Classic-Minesweeper`와 동시에 사용하면 플로팅 버튼과 `/ms` 명령이 중복될 수 있으므로 기존 확장은 제거하거나 비활성화하는 것을 권장합니다.

## 슬래시 명령

```text
/minigames
/mg
/games
```

미니게임 창을 열거나 닫습니다.

```text
/mg menu
/mg minesweeper
/mg spider
/mg territory
/mg close
/ms
/spider
/territory
```

`/미니게임`, `/지뢰찾기`, `/스파이더`, `/땅따먹기`도 사용할 수 있습니다.

## 조작

- 상단 `⌂`: 현재 게임을 끝내고 게임 목록으로 돌아가기
- 상단 `×`: 창을 닫고 현재 게임 일시정지
- 지뢰찾기 웃는 얼굴: 확인 후 새 게임
- 스파이더 `새 게임`: 확인 후 새 게임
- 스파이더 `↶ 되돌리기`: 직전 카드 이동 또는 카드 배분 복원, 횟수 제한 없음
- 스파이더 `💡 힌트`: 가능한 카드 이동이나 다음 카드 배분 위치 표시, 횟수 제한 없음
- 스파이더 카드 묶음: 직접 드래그하거나, 이동할 묶음과 목적지를 차례로 누르기
- 스파이더 카드 더미: 각 열에 카드 한 장씩 추가
- 땅따먹기 PC: 방향키/WASD로 이동, 스페이스바로 출격 준비
- 땅따먹기 모바일: 게임판 스와이프 또는 방향 버튼으로 이동, `선 긋기`를 누른 뒤 빈 영역으로 출격

새로고침하면 진행 중인 게임은 초기화됩니다.
