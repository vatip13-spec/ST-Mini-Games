# Mini Games for SillyTavern

생성 응답을 기다리는 동안 가볍게 플레이할 수 있는 미니게임 확장입니다. API를 사용하지 않으며 채팅, 캐릭터, RP 내용에 접근하지 않습니다.

## 포함된 게임

### 지뢰찾기

- 기존 `ST-Classic-Minesweeper`의 게임 규칙과 조작 유지
- 초급: 9×9, 지뢰 10개
- 중급: 16×16, 지뢰 40개
- 첫 클릭 안전 처리
- PC: 좌클릭으로 열기, 우클릭으로 깃발
- 모바일: 짧게 눌러 열기, 길게 눌러 깃발
- 모바일용 `칸 열기 / 깃발` 모드
- 초급에서는 게임판 너비에 맞춰 창과 상태바 폭 자동 축소
- 모바일 중급에서는 16열이 내부 폭을 빈틈없이 채우도록 칸 크기 자동 계산

### 스파이더 카드게임

- 한 무늬(스페이드) 고정
- 10열, 104장, 완성 묶음 8개
- 내림차순 카드 묶음 이동
- 드래그 이동과 탭 선택 이동 지원
- 횟수 제한 없는 되돌리기
- 횟수 제한 없는 힌트와 이동 위치 강조 표시
- 모바일 화면 폭에 맞춰 카드 크기와 간격 자동 조절
- 카드 드래그 중 페이지 스크롤 잠금
- PC에서는 카드가 쌓여도 게임판 높이를 고정하고 내부만 스크롤
- 빈 열이 있으면 새 카드 배분 불가
- K부터 A까지 완성된 묶음 자동 제거

## 공통 기능

- `🕹️` 플로팅 버튼으로 열기/닫기
- 플로팅 버튼과 게임 창 드래그 이동
- 모바일 화면 밖으로 버튼과 창이 벗어나지 않도록 자동 보정
- 창을 닫으면 진행 상태를 유지한 채 타이머 일시정지
- 게임 목록으로 돌아가면 현재 게임 종료
- 두 게임 모두 새 게임 시작 전 확인창 표시
- Windows Classic / 현재 실리태번 테마 / 사용자 테마
- 사용자 테마 생성, 복제, 삭제, JSON 내보내기·불러오기
- 기존 지뢰찾기 테마 JSON도 불러오기 가능

## 설치

1. 압축을 풉니다.
2. `ST-Mini-Games` 폴더 전체를 다음 위치 중 하나에 넣습니다.
   - 사용자별 설치: `SillyTavern/data/<사용자>/extensions/`
   - 전체 사용자 설치: `SillyTavern/public/scripts/extensions/third-party/`
3. SillyTavern을 새로고침합니다.

확장 폴더 이름은 `ST-Mini-Games` 그대로 유지해 주세요. 기존 `ST-Classic-Minesweeper`와 동시에 사용하면 플로팅 버튼과 `/ms` 명령이 중복될 수 있으므로 기존 확장은 제거하거나 비활성화하는 것을 권장합니다.

## 슬래시 명령

```text
/minigames
/mg
/games
```

미니게임 창을 열거나 닫습니다.

```text
/mg menu
/mg minesweeper
/mg spider
/mg close
/ms
/spider
```

`/미니게임`, `/지뢰찾기`, `/스파이더`도 사용할 수 있습니다.

## 조작

- 상단 `⌂`: 현재 게임을 끝내고 게임 목록으로 돌아가기
- 상단 `×`: 창을 닫고 현재 게임 일시정지
- 지뢰찾기 웃는 얼굴: 확인 후 새 게임
- 스파이더 `새 게임`: 확인 후 새 게임
- 스파이더 `↶ 되돌리기`: 직전 카드 이동 또는 카드 배분 복원, 횟수 제한 없음
- 스파이더 `💡 힌트`: 가능한 카드 이동이나 다음 카드 배분 위치 표시, 횟수 제한 없음
- 스파이더 카드 묶음: 직접 드래그하거나, 이동할 묶음과 목적지를 차례로 누르기
- 스파이더 카드 더미: 각 열에 카드 한 장씩 추가

새로고침하면 진행 중인 게임은 초기화됩니다.
